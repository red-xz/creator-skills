# Good First Issues

Small, well-scoped tasks for first-time contributors. Pick one, open a
pull request, and mention this file. No need to ask first — but if you
want to claim a task, open an issue and say you are working on it.

## New skills (follow the format in CONTRIBUTING.md)

1. **Add a `runway-shorts` skill** — Runway Gen-4.5 for Shorts: specs,
   pricing, character consistency, honest volume math, and how it
   compares to Kling and Veo. The kling skill notes Runway was not deeply
   researched — this fills that gap.
2. **Add a `capcut-editing` skill** — editing Shorts in CapCut: caption
   styling, the 3–8s visual-change rule, export settings for Shorts, and
   the free-vs-Pro split.
3. **Add a `thumbnail-design` skill** — designing Shorts thumbnails:
   the 3-second glance test, safe zones, text rules, and 2–3 worked
   before/after examples. (The SEO skill covers thumbnail rules briefly;
   this goes deep.)
4. **Add a `firebase-hosting-cache` skill** — Firebase Hosting cache
   behaviour for web apps: why returning visitors can get a mixed build
   after a deploy, and the `Cache-Control: no-cache` fix for html/js/json.

## Templates & docs

5. **Add a long-form script template** (`templates/long-form-script.md`)
   — the same structure as `short-script.md`, extended for a 8–15 minute
   video: hook, chapters, rehooks, payoff, end screen.
6. **Translate the README into Bengali** (`README-bn.md`) — a large share
   of this bundle's audience reads Bengali first.

## Quality

7. **Check the prices** — verify the Kling, Veo/Flow, and Google AI plan
   prices in `kling-shorts` and `veo-flow-ingredients` against the
   vendors' current pages, and update the "checked" dates. Prices change
   often; this needs doing every few months.
8. **Fix or clarify anything confusing** — if a sentence confused you, it
   will confuse the next reader. Small clarity PRs are welcome.
