# Package a Short

Run this for one finished Short, before upload. Loads
`youtube-shorts-seo` for the rules; this file is the checklist.

## 1. Target phrase (before anything else)

- [ ] One target phrase chosen, based on search demand (autocomplete,
      Studio Research tab, Trends, or a keyword tool)
- [ ] Phrase is specific enough that a small channel can rank for it —
      not the head term the big channels own

## 2. Title

- [ ] Target keyword in the first 5 words and first 50 characters
- [ ] 40–70 characters, not all-caps
- [ ] Three approaches drafted (direct / question / number-led), best one
      chosen by the video
- [ ] Title promises only what the video delivers

## 3. Description

- [ ] First line: keyword + 1–2 sentence summary, unique to this video
- [ ] Link to a playlist or long-form video
- [ ] 3–5 hashtags on their own line (1 broad, 1 category, 2–3
      topic-specific) — never #viral #trending #fyp
- [ ] Standard footer appended
- [ ] No keyword stuffing, no tags in the description

## 4. Tags

- [ ] 3–5 broad tags (exact topic phrase, common misspellings,
      brand/place names)
- [ ] Total tag text under 500 characters

## 5. Thumbnail

- [ ] 2–3 clearly different thumbnails prepared (9:16, 2160×3840)
- [ ] Max 3 elements; 2–4 short words of bold high-contrast text
- [ ] Text complements the title, never repeats it
- [ ] Subject + text inside the central safe zone (~900×1160 px)
- [ ] 3-second glance test at mobile size: the eye knows where to go

## 6. Spoken + on-screen keyword

- [ ] Target phrase said aloud in the opening seconds
- [ ] Hook-text overlay carries the title's keyword

## 7. Retention check (watch the final cut once, properly)

- [ ] Speech/payoff within 2.5s of the first frame
- [ ] Something visible changes every 3–8s; no 8s+ static stretch
- [ ] Loop opened in the first 5s, payoff held to 55–85%
- [ ] First 7s confirm the packaging promise
- [ ] Burned captions present, 1–6 words per screen, never covering a face
- [ ] Ends on the payoff; end-card CTA tight (~5s)

## 8. Upload settings

- [ ] Related-video link set (the only clickable link a Short has)
- [ ] Short added to a themed playlist
- [ ] AI disclosure = YES if any clip is AI-generated
- [ ] Language + category set (or covered by upload defaults)

## 9. After upload

- [ ] Check Reach tab at 7 and 28 days (queries, CTR per query)
- [ ] Low CTR + healthy impressions → new thumbnail, reworked title
- [ ] Flat impressions → rewritten description
- [ ] Do NOT delete a slow starter; do NOT delete and repost
