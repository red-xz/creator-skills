# Plan a Shorts Week

Pick the week's topics, check they are not already covered, and spread
them across the week. Loads `youtube-shorts-seo` and
`youtube-hype-2026` for the rules.

## 1. How many?

- Decide the week's volume honestly. Leaders post ~0.5–1 Short/day;
  packaging beats volume. Three a day only works if every one of them is
  packaged properly — if quality slips, cut volume first.

## 2. Pick topics

- [ ] Each topic passes the test: a named person or animal, extreme
      stakes, a payoff held to the end. If you cannot say the payoff in
      one sentence, the topic is not ready.
- [ ] Mix the week: at least one topic from a different angle than the
      last few weeks (check what other channels already covered — do not
      post an angle they already did).
- [ ] For a history channel: accuracy is the differentiator. Verify every
      claim against a real source before scripting; never ship a fact you
      cannot source.
- [ ] For a gameplay channel: real footage + your own commentary/analysis
      — narration that only describes the action does NOT count as
      original under the Oct 2026 rules.

## 3. Check for duplicates

- [ ] Search the channel's own catalog for each topic — no covered story
      built twice.
- [ ] Check the week's topics against each other: one target phrase per
      video, a cluster across the week, not the same keyword five times.

## 4. Package before production

- [ ] Title + thumbnail concept decided for each Short BEFORE production
      starts — not at upload.
- [ ] Each Short has its one target phrase written down (see
      `templates/short-metadata.md`).

## 5. Spread the week

- [ ] Slots spread across the week; never double-book a slot.
- [ ] If a long-form video ships this week, its first 7 days matter most
      (Hype window, once eligible) — front-load promotion and ask the
      audience to hype in the first days.
- [ ] Leave one slot unfilled if the week is tight. A skipped day beats a
      rushed Short.

## 6. Review last week (5 minutes)

- [ ] Which Shorts beat baseline, which stalled — check Viewed vs Swiped
      Away and Average View Duration, not just views.
- [ ] One lesson written down from the best and the worst performer.
      Change ONE thing at a time across several Shorts; one Short proves
      nothing.
